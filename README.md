# Yogya Journeys

═══════════════════════════════════════════════════════════

BRAND FOUNDATION

═══════════════════════════════════════════════════════════

Agni Aksa Tours is a premium private VIP tour operator in Yogyakarta, Indonesia, offering chartered EV touring for discerning foreign travelers. Positioning: eco-luxury, heritage-focused, understated confidence — never loud, never generic, never a template-feeling travel site. Internal philosophy (never printed as a visible tagline): "Under Promise, Over Deliver."

Brand voice: elegant, warm, precise. Short sentences. Confidence without hard-sell. Speaks to travelers who want silence, comfort, and cultural depth — not a crowded minivan tour group.

Booking model: 100% WhatsApp-first. There is no online payment checkout in this version — every "Book" or "Chat on WhatsApp" action opens a WhatsApp chat with a pre-filled message. No user accounts, no login, no cart persistence beyond a single browsing session.

DESIGN SYSTEM

═══════════════════════════════════════════════════════════

COLOR PALETTE

- Deep Indigo (primary dark bg): #1B1F3B

- Antique Gold (accent, CTAs, highlights): #C9A96E

- Warm Ivory (light bg): #F5F1E8

- Charcoal (body text on light): #2B2B2B

- Muted Bronze (secondary accent/borders): #8C7355

TYPOGRAPHY

- Headlines: elegant serif (Cormorant Garamond, Playfair Display, or closest equivalent available). Use italic styling on emphasis words within headlines (e.g. "Curated in *Silence*") — this italic-gold-accent-word pattern should repeat consistently across every page headline.

- Body: clean sans-serif (Inter, Lato, or equivalent), highly legible at mobile sizes.

- Avoid all script/decorative fonts entirely.

RECURRING MOTIFS

- Stupa-and-spire SVG skyline silhouette (already established as the site's core visual signature) — reused as a thin horizontal divider graphic at every major light/dark section transition, instead of a flat color cut. This should feel like one continuous illustration system stitching the page together, not decoration bolted on per-section.

- Low-opacity (4–6%) batik pattern watermark behind indigo/dark sections only — barely visible, felt more than seen. Never appears on ivory/light sections.

GLOBAL PERSISTENT ELEMENTS

- Sticky floating WhatsApp button: gold circular icon button, bottom-right, icon-only by default, expands to show "Chat on WhatsApp" label on hover/tap. Appears only after the visitor scrolls past the Hero section (not visible on initial load). Present on every page.

- Primary CTA label used everywhere, with zero exceptions: "Chat on WhatsApp" — never "Book Now," never a generic "Submit" or "Learn More" for primary actions. Behavior: opens https://wa.me/[PLACEHOLDER_NUMBER] with a context-aware pre-filled message reflecting whatever the visitor was looking at (e.g. selected tier, selected product).

BACKGROUND RHYTHM — "DAY TO DUSK" NARRATIVE

Do not alternate light/dark sections arbitrarily. Follow this deliberate sequence so that scrolling the page subconsciously mirrors a full day in Jogja, sunrise to dusk:

- Ivory/cream = rational, product-oriented content (trust-building, process, package selection, catalog browsing)

- Deep Indigo = emotional, reflective content (heritage storytelling, quiet moments, testimonials, urgency offers, closing)

MOTION PRINCIPLES (apply throughout, both pages)

- All scroll-reveal motion: fade + slight upward rise (translateY ~16–24px to 0), eased, never a hard snap or bounce.

- Staggered reveals (grids/cards): ~80–100ms delay between siblings, left-to-right or top-to-bottom depending on layout.

- Numeric counters (ratings, stats, live prices): animate as a count-up/count-down tween, never appear as static instant text.

- Hover states: subtle scale (1.00 → 1.02–1.04 max), never dramatic pop, shadow, or rotation — this brand does not do playful/bouncy motion anywhere.

- Accordion/expand interactions: smooth height + opacity transition, ~250ms ease-in-out.

- Nothing on this site should feel like a "gamified" SaaS product. Every transition should feel unhurried, arranged, precise — matching the actual in-car guest experience being sold.

CRITICAL BUILD NOTES

═══════════════════════════════════════════════════════════

- Do not substitute any stock "generic travel site" visual patterns (large search-bar hero widgets, bright primary-color CTA buttons, card-heavy dashboards). Every visual choice should trace back to the quiet-luxury, heritage-focused brand described above.

- Every image brief above must be treated as genuinely distinct — no two images on the site should share a color temperature, angle, or time-of-day treatment, even when depicting the same subject (e.g. Borobudur appears three separate times across these two pages, each time visually different).

- All pricing shown is placeholder and should be built as editable/configurable values, not hardcoded — real figures pending a final unit-economics pass.

- WhatsApp number is a placeholder — build the link structure to be trivially swappable.

- This is a two-page build. Do not invent additional pages, navigation items, or footer links beyond what's specified here.
